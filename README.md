# Ментальна математика

Вебзастосунок для занять ментальною арифметикою на соробані. Основний інструмент — фізичний абакус:
екран показує завдання, перевіряє відповідь і за потреби демонструє рухи кісточок.

## Що є

- Карта з чотирма світами й 35 рівнями — по одному на кожен прийом (прямі рухи, через 5, через 10, комбіновані).
- Генератор прикладів, який добирає числа під поточне положення кісточок і дозволені прийоми.
- Тренажер: довільна тема, кількість прикладів і дій, розрядність, режим «на абакусі» або «подумки», показ чисел із темпом.
- Облік засвоєння окремо для фізичного й ментального рахунку, статистика для батьків.
- Блоки за заняття й острів для будівництва.
- Робота без інтернету після першого відкриття.

## Запуск

```bash
npm install
npm run dev      # розробка
npm test         # тести
npm run build    # збірка в dist
npm run preview  # перегляд зібраної версії
```

## Розміщення

Кожен push у гілку `main` запускає тести, збірку й публікацію на GitHub Pages
(`.github/workflows/deploy.yml`).

## Дані

Прогрес зберігається лише в браузері на пристрої (`localStorage`) і нікуди не надсилається.
Резервну копію можна зберегти у файл у розділі «Для батьків».
