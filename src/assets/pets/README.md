# Оновлені супутники

10 прозорих Minecraft-подібних тварин, окремо згенерованих вбудованим `image_gen` за початковими спрайтами та схваленим користувачем напрямом Яри й Грома. Збережено всі id, імена, види, основні кольори й характерні риси тварин.

Фінальні WebP мають ширину 640 px і разом займають 342 584 байти. Повні промпти та параметри підготовки містяться в `generation.json`.

`src/game/companion/artwork.ts` містить статичні імпорти й розміри. `PetSprite` зберігає доступні назви й класи настрою, а при помилці завантаження показує старий спрайт. Наявні id продовжують працювати зі збереженнями та репліками. Vite включає зображення до збірки з хешованими назвами, а наявний service worker кешує їх для роботи без мережі.
