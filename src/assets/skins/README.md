# Оновлені скіни

17 прозорих Minecraft-подібних аватарів, згенерованих вбудованим `image_gen` за старими спрайтами та схваленим користувачем блоковим концептом. Збережено наявні id, назви, палітри й основні мотиви одягу. Для «Нічної зірки» використано біле волосся й темний капюшон зі схваленого концепту.

Спільний промпт, описи всіх персонажів і параметри підготовки записано в `generation.json`.

Фінальні файли — WebP із прозорістю, висотою 768 px, загальним розміром близько 566 КБ. Це зображення аватарів для застосунку, а не UV-текстури для імпорту в Minecraft.

`src/game/skins/artwork.ts` містить статичні імпорти, розміри й квадратне кадрування голови. `Avatar` використовує той самий файл для фігурки та значка, а в разі помилки завантаження повертається до старого спрайта. Vite додає файлам хеші; наявний service worker включає їх до офлайн-кешу.

При заміні зображення слід зберегти id і перевірити кадрування обличчя в значку 30×30 px, повну фігуру в картці вибору й прозорі краї на світлому та темному фоні.
